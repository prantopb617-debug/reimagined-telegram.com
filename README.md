# Neon Orb Runner 🚀

A fast-paced 3D neon-themed endless runner game built with **Three.js** and vanilla JavaScript. Dodge obstacles, collect neon orbs, maintain combos, and grab shields to survive as long as possible in a cyberpunk-inspired city!

## Features ✨
* **3D Graphics & Visuals:** Powered by Three.js with glowing neon lighting, custom particle explosions, and dynamic starfields.
* **Combo System:** Collect consecutive orbs to multiply your score and unlock bonus lives.
* **Power-ups:** Pick up shield boosters to protect yourself from incoming obstacles.
* **Responsive Controls:** Supports both Desktop (Keyboard A/D or Arrow Keys) and Mobile devices (Touch/Swipe or On-screen buttons).
* **Local High Scores:** Saves your top 5 scores directly to your browser's LocalStorage with Bengali date formatting.

## Controls 🎮
* **Desktop:** Use **A / D** or **Left / Right Arrow Keys** to change lanes. Press **P** to pause.
* **Mobile:** Use the on-screen **◀ / ▶** buttons or swipe left/right.

## Technologies Used 🛠️
* HTML5 / CSS3
* JavaScript (ES6 Modules)
* Three.js (via CDN Import Map)
